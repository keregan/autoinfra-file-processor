# AutoInfra File Processor

Сервис автоматизации обработки, сортировки и резервного копирования файлов.

AutoInfra File Processor - предназначенный для упрощения рутинной работы с файлами в инженерных, офисных и бизнес-процессах.

Сервис автоматически сканирует директории, обрабатывает входящие файлы, создаёт backup-копии, сортирует файлы по типам и сохраняет логи обработки.

---

# Функционал проекта

- автоматическая обработка файлов
- определение типа файлов
- автоматическая сортировка файлов
- backup-система
- logging обработки
- поддержка environment variables
- Docker контейнеризация
- поддержка Docker Compose
- CI/CD интеграция
- конфигурируемая инфраструктурная структура

# Как использовать проект

## 1. Подготовка

Перед запуском убедитесь, что установлены:

- Docker
- Docker Compose
- Git
- Python 3.13+ (для локального запуска без Docker)

---

## 2. Клонирование репозитория

```bash
git clone https://github.com/keregan/autoinfra-file-processor.git
cd autoinfra-file-processor
```

---

## 3. Настройка `.env`

Создайте или настройте `.env` файл:

```env
INPUT_DIR=input
PROCESSED_DIR=processed
BACKUP_DIR=backup
LOG_DIR=logs
```

---

## 4. Добавление файлов

Поместите файлы для обработки в директорию:

```text
input/
```

Например:

```text
input/
 ├── report.pdf
 ├── image.png
 ├── table.xlsx
```

---

## 5. Запуск проекта

### Через Docker Compose

```bash
docker compose up --build
```

---

### Локальный запуск

```bash
python app/main.py
```

---

## 6. Результат обработки

После запуска сервис:

- создаст backup-копии файлов
- определит тип файлов
- отсортирует файлы по директориям
- сохранит логи обработки

Пример результата:

```text
processed/
 ├── pdf/
 ├── images/
 ├── spreadsheets/
 └── other/
```

---

## 7. Просмотр логов

Логи обработки доступны в:

```text
logs/processor.log
```

---

## 8. Остановка контейнеров

```bash
docker compose down
```

---

# Поддерживаемые типы файлов

На текущем этапе сервис поддерживает автоматическую обработку:

- PDF документов
- текстовых документов
- таблиц
- изображений
- инженерных чертежей
- неизвестных типов файлов

Пример:

```text
.pdf   -> processed/pdf/
.docx  -> processed/documents/
.xlsx  -> processed/spreadsheets/
.png   -> processed/images/
.dwg   -> processed/drawings/
other  -> processed/other/
```
