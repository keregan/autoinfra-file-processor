# AutoInfra File Processor

Мини-проект для автоматизации обработки, сортировки и резервного копирования файлов.

Проект предназначен для автоматизации рутинных операций с файлами в инженерных, офисных и бизнес-процессах.

---

# Возможности проекта

Планируемый функционал:

- автоматическая обработка файлов
- сортировка файлов по типам
- создание backup-копий
- logging операций
- Docker контейнеризация
- запуск через Docker Compose
- CI/CD pipeline
